The plan

From inbox to expense record.

Start small: one dedicated inbox, one bank’s alerts, and a connection that works reliably.

  1. 01

    Forward an alert

    The owner forwards selected bank transaction emails to a dedicated Gmail inbox.

  2. 02

    Read the details

    With the owner’s permission, the planned importer reads alerts to identify the amount, currency, merchant and transaction date.

  3. 03

    Review the record

    The planned tracker keeps expenses together for personal review, with uncertain details flagged for checking.

Permission, explained

Why Gmail access?

Transaction details arrive by email. Reading those alerts is how Street Expenses is intended to reduce manual expense entry.

The planned permission is read-only Gmail access. It allows reading mail across the connected mailbox; a forwarding filter does not technically restrict that permission to selected messages. That is why this project uses a dedicated inbox.

This permission does not allow sending, editing or deleting email. Street Expenses does not ask for a Gmail password or a bank login.
